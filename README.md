# Agent Room

클로드(Claude Code)·코덱스(Codex)·오픈코드(OpenCode)가 한 방에 들어와 같이 일하는 단톡방이에요. 태블릿 Termux 안의 우분투에서 돌아가고, 크롬으로 열어 써요. 기존 Pad Chat(8766)은 건드리지 않고 8777 포트를 따로 써요.

## 설치 (처음 한 번)

Termux에서:

```
curl -fsSL https://raw.githubusercontent.com/dyahn99-cell/agent-room/main/install.sh -o install.sh
bash install.sh                                # 공개 저장소
AGENT_ROOM_TOKEN=깃허브토큰 bash install.sh     # 비공개 저장소
```

예전 zip으로 설치했던 경우에도 그대로 돌리면 돼요. 대화방과 설정은 유지돼요.
처음이면 로그인을 한 번 해요: `proot-distro login ubuntu` → `claude` → `codex login` → `exit`

## 업데이트

앱 왼쪽 아래 버전 옆에 "업데이트"가 뜨면 눌러서 받으면 끝이에요. 서버가 알아서 다시 켜져요.

## 쓰기

```
~/start.sh      # 서버 켜고 크롬으로 열기
~/stop.sh       # 끄기
```

크롬 메뉴 → "홈 화면에 추가"를 하면 아이콘으로 앱처럼 열려요.

## 방에서 쓰는 법

- `@클로드` `@코덱스` `@오픈코드`로 부르고, `@전체`면 셋이 차례로 답해요. 안 부르면 마지막에 대화한 AI가 답해요.
- 위쪽 **작성 권한**에서 고른 AI만 파일을 고쳐요. 나머지는 읽기·검토만 해요.
- 작성 권한이 있는 AI가 작업할 때마다 변경 내역 보기와 **되돌리기**가 생겨요.
- AI끼리 서로 부르면 자동으로 이어서 답하고, 방 설정의 횟수(기본 3번)에서 멈춰요.
- 스크린샷은 붙여넣거나 클립 버튼으로 첨부해요.
- 위쪽 사람 모양 버튼(AI 설정): 모델·추론 강도 변경, 역할(판단/구현/확인), 방 참여 끄기, 기억 초기화. 모델을 바꿔도 방 대화는 이어서 넘겨줘요.
- 상자 모양 버튼(결과물): 작업별 변경, 처음부터 전체 변경, 바뀐 이미지 모아보기.
- 변경이 생긴 작업엔 승인/반려 버튼이 있어요. 반려 이유는 그대로 다음 지시가 돼요.
- **자료 폴더**: 전문가·패널 → 전문가 고치기에서 사양서·단가표·카탈로그(PDF·워드·파워포인트·엑셀·텍스트)를 넣어두면, 그 전문가가 답하기 전에 먼저 찾아보고 어느 파일을 봤는지 밝혀요. 답 아래 📚 표시를 누르면 원문을 볼 수 있어요.
- 실패하면 원인 한 줄과 "다시 시도" 버튼이 떠요.
- 작업이 끝나면 알림이 와요 (Termux:API 앱이 있으면 Termux 알림, 없으면 크롬 알림).

## 설정 바꾸기 (우분투 안 `/root/agent-room/config.json`, 없으면 새로 만들기)

기본값은 `config.default.json`에 있고, `config.json`에 바꾸고 싶은 것만 적으면 그게 우선이에요. 업데이트해도 `config.json`은 안 건드려요.


- 오픈코드 모델: `"model": "opencode/big-pickle"` → 다른 무료 모델로 바꿔도 돼요 (`opencode models opencode`로 목록 확인)
- 코덱스가 작업할 때 명령이 막히면 `"writeSandbox": "danger-full-access"`로 바꿔보세요. 우분투(proot) 환경에선 코덱스 샌드박스가 안 먹힐 수 있어요. 안전장치는 되돌리기로 대신해요.
- 바꾼 뒤엔 `~/stop.sh` → `~/start.sh`
